# travel-fitness

Fitness app where people can buy courses from exclusive trainers

# Basic Interface Framework:

- [ ] React Native: IOS/Android
- [ ] Expo-router
- [ ] Firebase: firestore, storage, authentication
- [ ] xcode integration with a start script
- [ ] state persistance

# Motivation

My friend Sean Towns wants to create an online platform where he can sell a course. He wants to bundle different workout videos to sell together. He wants to be able to reach a larger audience and push his current customers to work harder.

# Description:

Travel Fitness is an all in one mobile app on IOS or Andriod where people get to work with exclusive trainers. People will be able to sign up and make an account. Once they do, they get to choose from an asortment of trainers with different specialties to buy their course from. Trainers can only be added if they are sponsered by the app, and no regular person can sign up to be a trainer, only a client. It's a subscription based program. The trainers are able to build workout regiments with checklists, goal dates, and videos to sell to their clients. They can have a meal plan section where they share daily home cooked meals with them. Each meal video can be equiped with an in depth recipe. Then there is a built in chart where you can see your progress as you check off different tasks, make different meals, etc. Everything is tracked to a particular goal. The user levels up as they progress through the trainer's course. There is a section where you can enter your weight, height, gender, and more health information to track all in one place accompanied with a chart to show progression over time. There will also be a predictive AI Chart where it can show you your potential progress based on your current trends.

# Phases of development

## Phase 1

The first phase of this app is basic development. When first logging on, the user chooses trainer or client. The trainer button will take them to a password page where they can enter with a password provided to them by the developer. Then from there, there will be a profile creation page for the respective roles.

structure of the entire app should be as follows:

- home page that says "Welcome {user} to your fitness journey through Travel Fitness"

The user will be able to create their user profile, and enter in their current statistics(weight, body fat %, muscle %, height, age, gender, etc.) and what their goal weight is, as well as a little extra description as to what exactly they are working towards. Then the user will have a chart which tracks progress everytime they enter in new data. Then I want to only work with a single trainer to keep it simple. The user will be able to purchase the single trainer's course and dive in.

The general structure of the course section should have a home/welcome page with texts and pictures, a communtiy chat section, a posts section where only the trainer can post videos/images or text threads, and a course section for all the users to see all courses available by the trainer.

On the trainer's end of the app, he should be able to edit all above sections. For the posts, when he wants to make a video/image post, he can add a caption, use hashtags, tag users, and add a location. The text thread should allow for emojis to be used. In his settings, he can choose theme colors for his course site, he should be able to toggle the community chat to be disabled so people can see it, but not interact with the chat. In the course tab, have a "create course" button that will open up a modal for the trainer to create a course for the users. The create a course section should have a lesson block format where for each lesson the trainer can upload a video. Accompanied with that is a custom checklist the trainer can setfor the client to be able to check off as they get through the video. The trainer can also add a description. Then they can add another lessons with the list going up to 10 lessons per course.

There will also be an in-app calendar that functions with the rest of the app to track the user's progress. I want there to be a mini calendar of the current week (sunday-saturday) on the home page, and a by month calendar when the user clicks into it. The calendar will having appointments and updates based on the interactions they have in the app such as weigh-ins, session bookings, cooking meals, completion of training sessions, etc.

I don't want there to be a pay wall for now, but have a clickable button to first enter the trainer's community.

## Phase 2

I want to branch out to have many different trainers. There will be a pay wall for each one. Then there will also be an AI chart to help predict future development. I want AI to help out a lot with facilitating so that there is an AI chatbot that can help the user with questions if the trainer is unavailable. I also want there to be section on the home page with an afirmation generated by the AI. There will also be a section where the trainers can do live streams and clients can view and interact with the stream in real time.

Trainers can also upload their training schedules and have clients book them on this app. They can post times/availability on the in-app calendar in and have clients choose times to either book the trainer for online sessions, in-gym training session, or at home sessions. For booking availabilty, there will be different timing selections for the different types of sessions, based on trainer's availabilty.

This should also be accompanied by notifications on updates, posts, new courses, or even if there hasn't been progress in a while, to motivate the user back to work.
